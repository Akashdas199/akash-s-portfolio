ELECTRICAL & ELECTRONIC ENGINEERING PORTFOLIO

Files:
- index.html: page content and structure
- style.css: black/ash responsive visual design
- script.js: floating pearls, mobile navigation, reveal animations, copy-email interaction

Preview:
1. Extract the ZIP.
2. Keep all three files in the same folder.
3. Open index.html in a browser.

Before publishing:
- Replace the sample email address (your.email@example.com).
- Add the person's name, LinkedIn profile, CV, and any contact details.
- Verify exact certificate titles and dates. Missing certificates are described transparently rather than invented.
- Consider adding a professional headshot and links to a GitHub/Google Scholar profile if relevant.
- The site uses Google Fonts from the internet; if offline, fallback fonts will display.

To publish for free, you can upload these files to GitHub Pages or Netlify.
